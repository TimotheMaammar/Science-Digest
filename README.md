# Science-Digest

A personal archive of research summaries across multiple disciplines.

Topics include biology, sport physiology, anthropology, population genetics, neuroscience, economics, and anything that does not belong in my
AI-focused repository, available at https://github.com/TimotheMaammar/AI/tree/main/RESEARCH_PAPERS

The underlying question is always the same: what does the evidence actually say?

Each summary includes paper metadata and a plain English synthesis covering context, results, and open questions.
